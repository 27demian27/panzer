# PANZER
_pre-alpha build_

_To run this build I suggest importing the `build.gradle` in your IDE of choice 
and then run `lwjgl3.Lwjgl3Launcher.main()`. 
Or you can run Gradle task `lwjgl3:run`_

### Contents
PANZER is a 2D top-down tank shooter game. Built entirely in Java, 
Logic and Physics from scratch, Graphics rely solely on the `ShapeRenderer` API 
from LibGDX to draw shapes. UI was made with the `scene2d` package from LibGDX.
The only assets used in this project is the _Black Ops One_ 
text font designed by James Grieshaber and Eben Sorkin.

The game currently features multiplayer limited to same device serving as 
a stepping stone to LAN, underlying networking logic is present and LAN 
multiplayer is close at hand.

It also features a world editor, bots and custom animations.
Keep in mind that this is nowhere near a finished game. It is a demo meant 
to showcase the current state of this software.
